Dropdown lists

One value per line. Every dropdown also has Other…, where people can type something not in the list — typed values are saved on the record but are not added here. Add a value here only when it is needed regularly.

Modules

Switch parts of the app on or off for this client. Organisation and Employees are always on. Switching a module off hides it and blocks it on the server, but never deletes its data — switch it back on and everything returns.

Languages

Switch on the languages users can choose. The screen is translated by Google Translate; everything saved stays in English — names, codes, amounts and dropdown values are never translated, letters always stay English, and typed text must be in English letters. With no language switched on, the app shows English only and no language button appears.
